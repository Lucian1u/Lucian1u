## 我在做什么

我想让 AI 的结果更可靠。输入要说清楚，遇到需要人决定的地方就停下来，完成以后还要能检查有没有漏掉。

目前的项目集中在这些方向。

- 把重复工作整理成可以直接调用的 Agent Skills
- 做无需复杂安装、尽量在本地运行的小工具
- 为内容生产建立可追溯、可复核的工作流

## 项目

### [Skill Shelf Check](https://github.com/Lucian1u/skill-shelf-check)

一个零安装、本地优先、只读的 Agent Skills 诊断工具。选择 Skills 文件夹后，它会标出缺字段、重名、全文重复、描述高度相似和本地链接失效等问题。

[在线使用](https://lucian1u.github.io/skill-shelf-check/) · [查看源码](https://github.com/Lucian1u/skill-shelf-check)

### [draft-lineage](https://github.com/Lucian1u/draft-lineage)

一个用于多稿合并的 Agent Skill。它先给段落和引文编号，遇到冲突就停下来等人决定，确认后再合稿，并用脚本核对内容是否遗漏。

[查看项目](https://github.com/Lucian1u/draft-lineage)

## 做事原则

- 先讲清楚工具不做什么，再讲它能做什么
- 重要判断保留证据，不能只靠模型自己宣布完成
- 本地能处理的内容，不要求用户先上传
- 演示、安装和验收都以别人能够复现为准
